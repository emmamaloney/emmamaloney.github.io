Projects

Rachel card game

A personal hobby project (in progress) during the summer of 2026. A simple website to simplify the scoring and gameplay of the cards game Rachel. The data from each game is continuously saved in a separate Google Sheets, which is later parsed by a Python programme into a Pandas dataset. This has then been analysed and graphed with the MatPlotLib library. The analytics backend is hosted by Render's free plan (and can therefore be painfully slow). Is programmed with Python, HTML, CSS, JS.
